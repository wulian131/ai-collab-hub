# 费用区别

| 项目 | 说明 |
| --- | --- |
| 本项目源码 | MIT 授权，没有软件授权费；不附带模型额度 |
| 自托管 | 使用者承担自己的主机、存储、网络和域名成本 |
| ChatGPT 登录的 Codex | 使用自己的有效套餐权益与限额；不保证所有账号/工作区均可用，也不保证无限调用 |
| API key 登录的 Codex | 按对应 API 组织用量计费，不因已有 ChatGPT 套餐自动抵扣 |
| Muse 或其他云端平台 | 使用者核对自己的平台能力、套餐和执行限制，项目不能控制其收费 |
| Apple 客户端 | Xcode 编译、签名与发行方式依使用者的 Apple 条件，源码不是 App Store 或 TestFlight 交付 |

官方文档区分 ChatGPT 订阅登录与 API key 的按量登录；该选择决定 Codex 的计费和适用控制。具体额度和价格会变动，不在本项目写死。[OpenAI 认证和计费说明](https://learn.chatgpt.com/docs/auth)

默认服务不调用模型；启动一个有执行权限的 worker 后，它会调用设备自己的 CLI。持续任务、协作续轮与并发会消耗资源。本项目没有统一 API 花费硬上限或跨 Agent 套餐计量；--once、timeout 和并发限制不是金额上限。需要严格预算时还需使用提供方支持的预算/用量控制，额度不足就停止执行器，不自动购买额度或切换付费方式。
